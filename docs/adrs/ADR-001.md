# ADR-001

## Title

Support Both Structured and Unstructured Enterprise Knowledge

---

## Status

Accepted

---

## Context

Early versions of PetroKnowledge AI were designed primarily as a Retrieval-Augmented Generation (RAG) platform for enterprise documents.

During architecture design it became clear that many enterprise questions cannot be answered using documentation alone.

Organizations also require access to structured operational data such as invoices, ERP transactions, CRM records and financial metrics.

---

## Decision

PetroKnowledge AI will support two complementary knowledge sources:

1. Unstructured enterprise knowledge (documents).
2. Structured operational data (databases and APIs).

Incoming questions will be analyzed by a Knowledge Router that determines how each request should be processed.

Possible strategies include:

- Document Retrieval (RAG)
- SQL Queries
- API Calls
- Hybrid Retrieval

---

## Consequences

Benefits include:

- Better enterprise accuracy
- Real-time operational information
- Reduced hallucinations
- Greater scalability
- Support for future enterprise integrations

The platform architecture becomes more modular while remaining adaptable to multiple industries.
